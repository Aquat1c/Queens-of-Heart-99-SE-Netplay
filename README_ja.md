# Queen's of Heart '99 SE Netplay

クイーンオブハート'99 SE にロールバック・ネットプレイ、最新のコントローラー対応、トレーニング機能、キャラクターのカラー自作、リプレイとリプレイ操作介入、観戦、ウィンドウ拡縮、ゲーム内オーバーレイを追加します。

ゲーム本体は含まれていません。対応ビルドの正規で完全なゲームを別途用意し、そこへこのパッケージをインストールしてください。

この文書は [README.md](README.md)（英語）の日本語版です。ライセンス条文は原文のままでなければならないため、README.md にのみ収録しています。

- ネットコード、リプレイ、観戦のしくみ（英語）: [docs/HOW_IT_WORKS.md](docs/HOW_IT_WORKS.md)

## 動作環境

対応ビルド:

| ランタイムプロファイル | 受け付ける実行ファイル |
|---|---|
| 11月 | 11/26 の製品版実行ファイル、および 2006年9月4日の PovertyHut Jr. コミュニティ版実行ファイル |
| 12月 | 12月版の実行ファイル |

判定の基準はファイルの日付ではなく、実行ファイルのハッシュの完全一致です。キャスターはメインメニューを表示する前に実行ファイルと必要なゲームファイルを確認し、インストールが不完全・改変済み・非対応の場合は、どのファイルを入れ替えればよいかを表示します。プロファイルが異なるプレイヤー同士は同じセッションに参加できません。

ほかに次のものが必要です。

- DirectX 9 が動作する Windows、または最近の Wine/Proton 環境。
- このパッケージ一式。EXE・DLL・ラッパーを他のリリースのものと混ぜて使わないでください。
- キーボードまたはコントローラー。`SDL3.dll` があるとコントローラー対応が最も良くなるので、キャスターと同じフォルダーに置いたままにしてください。

## インストール

1. ゲームフォルダーをバックアップしてください。特に既存の `ddraw.dll`。
2. 全ファイルを、ゲームの実行ファイルと同じフォルダーへ展開します。
3. `qoh99caster.exe` を実行します。このMODの使用中はゲームを直接起動しないでください。
4. 「設定 -> プレイヤーとファイル...」を開き、ニックネームとゲームのパスを設定します。自動で見つからなかった場合はネット対戦DLLも設定します。
5. 「操作設定」を開き、1P を割り当てます。ローカル対戦をするなら 2P も割り当ててください。
6. 確認を求められたら、`qoh99caster.exe` の UDP をファイアウォールで許可してください。

操作は8種類です。上・下・左・右・A（弱）・B（中）・C（強）・D。操作設定ではキーボードのキーとコントローラーのボタンを登録できます。コントローラーの移動は、方向を一度入力するだけで十字キーやスティック全体として登録できます。

ニックネームは日本語・キリル文字に対応しています。キャスター自体の表示言語は、設定の最上部にある「言語」の行で切り替えます。

## オンライン対戦

共有コードも公開ロビーもありません。一方がホストし、もう一方がホストのアドレスを入力します。

### ホスト側

1. 「設定 -> 接続... -> ホストポート」でポートを設定します。
2. 「ゲームをホスト」を選びます。
3. 相手に自分のグローバルIPとポートを伝えます。例: `203.0.113.40:7500`。キャスターで C を押すとアドレスをコピーできます。
4. 相手が参加すると、その回線に必要な遅延（ディレイ）とロールバックを示す1つの画面が両者に表示されます。確定してから、キャラクターとステージを選びます。

### 参加側

1. 「ゲームに参加」を選びます。
2. ホストの IPv4 アドレスを数値で `ip:port` の形式で入力します。保存済み／既定のポートで正しければポートは省略できます。
3. 計測された遅延とロールバックを確定し、キャラクターを選びます。

キャスターはまず直接接続を試み、必要に応じて自動ホールパンチを使います。

### 遅延とロールバック

事前に設定しておくものはありません。キャスターが回線を計測し、その推奨値で画面を開くので、そのまま確定するだけで構いません。数値は前の対戦から引き継がれません。計測したその回線に属する値だからです。

この画面では相手の選択も変化がそのまま見えます。相手の入力遅延が埋めきれない分を自分のロールバックが埋めるため、相手が遅延を1フレーム増やせば、自分に必要なロールバックが1フレーム減ります。逆もまた同じです。どちらがどれだけ負担しているかが画面に出るので、遠い回線を二人で分担できます。

拒否されるのは、どう設定しても救えない値だけです。つまり、入力が回線を物理的に渡りきる時間より短い保証しか残らない場合です。判定は平均ping基準で、最悪値のスパイク基準ではありません。良好な回線で低い値を選んだなら、その選択はそのまま残ります。確定時に引き上げが必要な場合は、キャスターがその旨を表示します。両者は2つの計測のうち悪い方を使います。

入力遅延は最大15フレーム、ロールバックは最大30フレームです。

### オンラインの操作

| 既定のキー | 動作 |
|---|---|
| `-` / `=` | 自分の入力遅延を減らす／増やす |
| `[` / `]` | 自分のロールバック幅を減らす／増やす |
| F1 | 現在の試合を終了し、両者をキャラクター選択へ戻す |
| （既定なし） | 試合からの退出。キーが必要なら「操作設定 -> モード操作設定」で割り当ててください |

HUD に現在の遅延とロールバックが表示されます。どちらも試合中、ラウンドの途中でも変更できます。キーが拒否するのは、入力が回線を物理的に渡りきれない値だけです。遅延を下げれば入力の手応えは良くなり、修正（巻き戻し）が増えます。上げればその逆です。自分のロールバックは相手の回線から自分を守り、自分の入力遅延は自分の回線から相手を守ります。

### キャラクター選択と再戦

- F1 を押すと両者がキャラクター選択へ戻り、現在のリプレイ記録が終了します。
- キャラクター選択では、B でその側の決定済みキャラクターを取り消せます。まだ選んでいない場合、B は何もせず、モード選択へ戻ることもありません。
- 継続確認で両者が YES を選ぶと、同じ組み合わせで即座に再戦します。どちらかが NO を選ぶと、接続を保ったまま両者がキャラクター選択へ戻ります。

### ポートとルーター

プレイヤーと観戦者は別々の UDP ポートを使います。ゲーム用ポートだけを開放すると、対戦はできるのに観戦はできない状態になります。そのためキャスターは、ホスト中だけ観戦用ポートの開放をルーターへ依頼し、ホストをやめると閉じます。NAT-PMP と UPnP に対応しています。ルーターが応じなくても損はありません。ホールパンチは変わらず動作します。

| ポート | 用途 |
|---|---|
| UDP 7500（ホストポート） | ゲーム用（対戦相手向け） |
| UDP 7501（ホストポート + 1） | 観戦者用 |

観戦用ポートは、自動設定でそのポートが空いていればゲーム用ポート +1 です。空いていなければシステムが割り当てます。「設定 -> 自分の試合の観戦設定...」でポートの確認と固定ができ、手動で開放するものも一覧できます。

## ネットワークの利用

キャスターの通信先は、入力したアドレスだけではありません。通信先は次がすべてです。

| 通信先 | タイミング | 目的 |
|---|---|---|
| 入力したアドレスと、そこからつながる相手 | ホスト、参加、観戦 | 対戦と観戦の通信 |
| `delthas.fr:14763` | ホールパンチの実行時 | 2台のマシンを引き合わせる公開パンチサービス。対戦の通信は流れません。`QOH99_PUNCH_RELAY_OVERRIDE` で変更できます。 |
| `https://api.ipify.org/`、次に `https://ipv4.icanhazip.com/` | キャスターの起動ごと | グローバルIPを検出して表示・コピーできるようにします。`QOH99_PUBLIC_IP_OVERRIDE` で変更できます。 |
| 自分のルーターのみ: NAT-PMP（ポート 5351）、UPnP（SSDP `239.255.255.250:1900`、その後 HTTP） | ホスト中 | 観戦用ポートの開放 |

**ファイアウォール。** `qoh99caster.exe` の UDP を許可してください。通常の対戦に TCP の待ち受けや制御チャンネルはありません。送信 TCP を使うのは、UPnP、グローバルIPの検出、自分で動かす任意のリレーだけです。

## 観戦

観戦の可否はホストが「設定 -> 自分の試合の観戦設定...」で決めます。

| 観戦できる人 | 効果 |
|---|---|
| ホストアドレスを知っている人全員 | 観戦者は確認なしで参加できます |
| 毎回確認する | 観戦者ごとに承認が必要です |
| 誰にも許可しない - 観戦用ポートを開かない | 観戦は無効です |

同じページで、同時に観戦できる最大人数も設定します。

観戦するには「ゲームを観戦」を選び、対戦で参加するときと同じアドレスを `ip:port` の形式で入力します。共有コードは不要です。経路は直接接続、次に自動ホールパンチの順で自動的に選ばれます。公開パンチサービスは通信を中継せず、公開の中継リレーもありません。リレー経路を使うには、誰かが `qoh99caster relay [--bind IP] [--port N]` を実行し、観戦者が `QOH99_RELAY_OVERRIDE` でそこを指定する必要があります。

ホストの観戦人数上限・上り回線・PC性能が許せば、複数人が同時に観戦できます。観戦は受信専用で、プレイヤーの入力や試合の内容に影響を与えることはできません。観戦したセッションは既定でリプレイとして保存されます。「設定 -> リプレイと保存先...」の「観戦セッションを保存」でオフにできます。

リプレイ用キーは自分の画面にだけ効きます。

| リプレイ用キー | 観戦中の動作 |
|---|---|
| 早送り | ライブまで飛ばす。セットの前の試合は全速で進みます |
| 低速 | 通常速度に戻す |
| 一時停止 | 停止と再開 |
| コマ送り | 1フレーム進める |

観戦は通常プレイヤーより約2秒遅れて進み、回線が一度詰まった観戦者はもう少し遅れます。遅れて参加した場合は自動で追いつきます。メニューやキャラクター選択は素早く、試合中は遅れの大きさに応じた速さで追いつきます。15秒以上または1試合以上遅れている間は、画面下の帯が早送りキーを定期的に案内します（8秒のうち3秒）。

観戦ウィンドウのタイトルバーが、今なにをしているかを表示します。

| タイトルの状態 | 意味 |
|---|---|
| CONNECTING | ホストへ接続中で、試合データはまだありません |
| JOINING | 試合へ合流中 |
| BUFFERING n/m | バッファを溜めている最中。数字が進み具合です |
| WAITING FOR THE MATCH | プレイヤーが出した分をすべて受け取り済みで、相手のゲームが一時停止中、読み込み中、またはラウンド間です |
| CATCHING UP | ライブより遅れて追いつき中。遅れも表示します |
| LIVE | 追いついた状態 |
| PAUSED | 自分の画面を一時停止中 |
| SEALED (n left) | 配信元は終了済みで、残り n 件の記録を再生中 |
| COMPLETE | すべて再生済み |
| FAILED | 失敗しました。理由はログにあります |
| REJECTED | ホストがこの観戦者を拒否しました |

## オフラインモード

「オフラインでプレイ」を選ぶと、次を選択できます。

| モード | 内容 |
|---|---|
| トレーニング | トレーニングモードと設定パネルを開きます |
| 対人戦 | ローカル対人戦。キャラクター選択から始まります |
| CPU戦 | ローカル対CPU戦。キャラクター選択から始まります |
| フリープレイ | ゲーム本来のメニューを開き、通常のオフラインモードを使います |

対人戦と CPU戦は、そのセッション全体の勝利数を数え、オンラインでニックネームが出る位置に、左右それぞれの合計を「Wins: N」として表示します。

### オープニングムービー

フリープレイはゲームのオープニングムービーから始まります。ゲームのオープニングムービーが Indeo 5 を使っている場合、Windows 10 と 11 はコーデックを持っていても登録していないため、音楽だけが鳴る黒い画面になります。同梱の `ddraw.dll` は、ゲームの実行中にそのゲームに対してだけデコーダーを登録します。システムには何もインストールせず、変更もせず、ムービーファイルにも手を加えません。同梱の `ir50_32.dll` を先に試し、Windows のものを予備として使うので、この DLL は任意です。

キャスター経由でも直接起動でも動作し、映像はウィンドウに合わせて拡大されます。攻撃ボタンでスキップできます。オンライン対戦・観戦・リプレイ・トレーニングでは再生されません。

### ゲーム本来のオフラインFキー

有効化した場合に限り、対人戦・CPU戦・フリープレイでのみ働きます。トレーニングは専用の操作を使い、これらのキーは無視します。

| キー | 動作 |
|---|---|
| F2 / F3 | 1P / 2P の CPU 操作を切り替え |
| F4 | HP/SP の自動回復を切り替え |
| F5 | キャラクター選択へ戻る |
| F6 | ラウンドをリセット |
| F7 | ゲーム本来の当たり判定表示を切り替え |
| F9 | 一時停止。F8 で1フレーム進む |
| F12 | フリーズ |
| Delete | 試合を終了 |

有効化するには、ゲームを閉じてから、キャスターの「設定 -> 追加機能(隠し F キー、FCommand.txt)...」で「隠しFキー (F2..F9)」を TRUE にし、「FCommand.txt に保存」を選びます。これだけで F8 と F9 も有効になります。保存先は `LocalConfig\FCommand.txt` です。

## トレーニングの操作

1P の設定済み操作で、2キャラクターを順に選びます。1人目を決定し、操作を一度離してから2人目を決定し、ステージを選びます。

| 既定のキー | 動作 |
|---|---|
| 1 | 位置をリセット |
| 2 | 選択中のスロットへステートを保存 |
| 3 | 選択中のスロットを読み込み |
| 4 | ダミーを配置してから記録する（下記参照） |
| 5 | ダミーの再生を開始／停止 |
| 6 / 7 | 前／次のスロット |
| 8 または F8 | 一時停止／再開 |
| 9 または F9 | 1フレーム進めて一時停止 |
| F1 | キャラクター選択へ戻る |
| F2 | ダミーの姿勢を切り替え |
| F3 | ダミーのガードモードを切り替え |
| F4 | 「すべて回復」の切り替え。両キャラクターが待機・歩き・しゃがみの間、HP・EX・ガードゲージを満タンに保ちます |
| F5（長押し） | EXゲージの端数を連続でためる |
| F6 | ラウンド開始位置に戻し、両キャラクターを待機状態にする |
| F7 | 攻撃判定・くらい判定・接触判定の表示を切り替え |
| Insert、またはコントローラーの Start | トレーニングパネルの開閉 |
| Backspace | 入力表示の切り替え |

これらは既定値です。「操作設定 -> モード操作設定」で、キーボードまたは選択中のコントローラーに割り当て直せます。F10、F11、F12、Delete はトレーニングの動作に割り当てられません。

### ダミーの記録は3回押し

キー4 は1つのキーで3段階です。体力ゲージの上の行に、次の押下が何をするかが表示されます。

| 押下 | 動作 |
|---|---|
| 1回目 | 配置。自分の操作がダミーを動かし、自分のキャラクターは動きません。どれだけ時間をかけても何も記録されないので、練習したい間合いまで歩かせてください。 |
| 2回目 | 記録開始。ダミーを置いた位置から始まります。 |
| 3回目 | 停止。記録した内容を保存します。 |

配置中は、キー5（またはメニューの「停止」の行）で、何も記録せず、スロットの再生もせずに抜けられます。そのスロットに既に入っている記録は、どちらの場合も手つかずのままです。

### 位置リセットの同時押し

| 入力 | 位置 |
|---|---|
| 1 のみ | ラウンド開始位置 |
| 1 + 左 | 左端 |
| 1 + 右 | 右端 |
| 1 + 下 | 中央 |

位置リセットはキャラクターの位置だけを動かし、体力・ゲージ・タイマー・ラウンド数はリセットしません。ステート保存と記録はそれぞれ8スロットあり、トレーニングセッションが終わると破棄されます。

### EXチャージ

F5 は端数ゲージ（ストック数の横の小さいバー）が満ちるたびにストックを1つ増やし、また端数をため直します。9ストックの状態で F5 を押す／長押しするとストックを0に戻し、同じ蓄積を最初からやり直します。

### トレーニングメニュー

Insert で、クイック設定・ダミー・トリガー・記録・表示・カラー・キー設定・ヘルプ・診断のタブが開きます。長いページは2段目の小さなタブに分かれます。左右キーかクリックで切り替えてください。「体力を全回復」は体力のみを回復します。「すべて回復」は体力・EX9ストック・ガードゲージ全体を回復します。自動回復の各設定は、両キャラクターが十分な時間待機し、対象の資源が満タンでないときに働きます。次のコンボを待つ必要はありません。

| 設定 | 場所 | 内容 |
|---|---|---|
| プレイヤー入れ替え | メニューの切り替え「ダミーはP1（操作はP2）」、既定のキーなし | どちらのキャラクターをダミー（ガードし、記録を再生する側）にするかを選びます |
| ガードタイミング | ダミータブ、ガード | ダミーがいつガードするかを決めます。「常時」が通常の動作です。「被弾後」は最初の1発を通し、設定したフレーム数だけガードして、攻めが途切れるとガードを解きます。フレームトラップの練習に向いています。「最初のガードまで」は1発ガードして止まるので、連係の残りが当たるかどうかが分かります。「ガード持続フレーム」の行で両方のタイマーを設定します。 |
| ダメージリデュース | ダミータブ、防御 | コンボを受けながら攻撃ボタンを素早く押すと、各ヒットのダメージが90%に、さらに速く連打すると70%になります。ゲーム内に説明はありません。左右それぞれについて、実戦どおりの判定なら「手動」、どちらかの強さに固定、きれいなダメージ値なら「オフ」を選びます。 |
| クリティカルヒット | クイック設定タブ、数値 | 攻撃する側ごとに、通常確率・常に発生・ランダムクリティカルなし・完全に無効・抽選値を指定 |
| 表示の切り替え | 表示タブ、判定表示 | 判定の各種類をプレイヤーごとに切り替えられます。ゲーム本来の表示が描く中心軸線も含みます。フレーム有利表示と入力表示は片側だけに限定できます。 |
| ランダム再生 | 記録タブの再生方法、トリガータブ | 「ランダム」は、選択中のスロットに関係なく、記録の入ったスロットから1つをランダムに再生します。「ランダムループ」は1回終わるたびに選び直します。トリガータブの「ランダム記録」は、イベントが発生するたびにランダムな記録スロットで応答します。 |

トレーニングは画面にも状態を表示します（フレーム有利表示の上）。保存・読み込み・消去・リセット・スロット変更は短時間表示されて消えます。配置中・記録中・再生中は終わるまで表示が残り、スロット番号も示します。

## カラーの自作

カラーは `CHARACTER_N.pal` という小さなテキストファイル（例: `SAORI_2.pal`）で、ゲームの隣の `palettes` フォルダーに置きます。N はキャラクター選択で選ぶカラースロット 1〜4 です。

### カラーを使う

キャラクター選択で色を選ぶときに D を押します。そのキャラクターとカラースロットに対応するファイルで試合が始まります。ファイルが無い場合は通常の色が使われます。オフラインでもオンラインでも動作します。

オンラインでは相手にも見え、観戦者にも見え、リプレイにも保存されます。オンラインで自分のファイルを着られるのは自分のキャラクターだけです。どちらかが自作カラーを選んでいる場合、両者が同じカラースロットを取れないという制限は解除されます。

試合中は Tab で自作カラーとゲーム本来の色を切り替えられます。オンラインでは、Tab は相手の見え方だけを変え、自分の自作カラーはそのまま残ります。別のキーを使うには、`ddraw_wrapper.ini` の `[Overlay]` にある `PaletteToggleKey` を設定してください。

### カラーエディター

トレーニングのゲーム内メニュー（Insert）にカラータブがあります。キャラクターの色をその場で編集できます。

- スロット（P1 か P2）と、オフラインならカラー 1〜4 を選びます。
- グリッドの色をクリックすると、RGB・HSV・16進入力と、明度・彩度のスライダーを備えたカラーピッカーが開きます。
- 数値の行をダブルクリックすると、正確な値を入力できます。
- 「元に戻す / やり直す」の行で変更を1つずつたどれます。Ctrl+Z と Ctrl+Y も使えます（ピッカーの中でも有効です）。
- 「カラー保存」は行に表示されたファイルへ書き出します。「カラー読み込み」で読み戻します。「初期カラー読み込み」はゲーム本来の色に戻し、「試合開始時のカラーに戻す」はこの試合が始まったときの状態に戻します。
- プレビューが自分のキャラクターと、飛び道具などそのキャラクターが出したものを表示します。
- ゲーム内の D ボタンでメニューを隠し、画面全体を確認できます。もう一度押すと戻ります。

保存されるファイルは通常の JASC 形式のパレットテキストなので、パレットを扱える画像ツールでも編集できます。

## リプレイの操作と操作介入

メインメニューの「リプレイ」から `.q99r` ファイルを閲覧・再生できます。記録の設定は「設定 -> リプレイと保存先...」です。

| セッション | 記録 |
|---|---|
| ネット対戦 | する（既定でオン） |
| ローカル対戦と Free Play | する（既定でオン） |
| 観戦セッション | する（既定でオン） |
| トレーニング、リプレイのリプレイ、CPU戦 | しない |

### リプレイ一覧での操作

| キー | 動作 |
|---|---|
| Enter | 選択中のリプレイを見る |
| P | 選択中のフォルダー（リプレイを選択中なら開いているフォルダー）の全リプレイを再生 |
| D | 選択中のリプレイの詳細 |
| Tab | 並び順を変更 |
| F | お気に入りの設定／解除 |
| Del / U | 削除／削除の取り消し |
| R | フォルダーを再スキャン |
| C | 検索や絞り込みを解除 |
| 左 / 右 | 一覧のページ送り |
| L | 対戦記録に入っていない試合を、リプレイファイルから補完する |
| Esc | 戻る |

初期の並び順は「Game order」です。新しいセットから表示し、各セット内は Game 1、2、3...の順に並びます。セットと試合番号の情報がないリプレイは録画日時の新しい順になります。「Alphabetical (A-Z)」はタイトルや名前の順、「Match count (most first)」は録画内の試合数が多い順です。セット内の試合番号とは異なります。

一覧は開いたときと R を押したときにスキャンします。スキャン中も現在の一覧と選択位置は維持されます。

連続再生は最初に記録された試合から始まり、同じゲームプロセスとウィンドウで続けて再生します。最初の試合は「Pause at replay start」の設定に従い、次の試合からは同じ表示設定で自動的に始まります。最後の勝利画面は1秒間表示して終了します。途中で閉じるか再生に失敗すると連続再生も止まります。検索や並び順は対象を制限しません。対象はフォルダー直下のファイルで、サブフォルダーは含みません。

対戦記録は一覧の横に表示されます。リプレイを選んでいるときは、その試合の結果、その試合が属するセットとその中での位置、その相手との通算成績が出ます。セットのフォルダーを選べばそのセットを表示します。試合は試合IDで対戦記録と結び付けられるため、名前を変えたり移動したりしたリプレイでも正しいセットに入ります。

### 再生

| 既定のキー | 動作 |
|---|---|
| Space | 一時停止／再開 |
| 右矢印 または `.` | 一時停止中に1フレーム進む |
| 左矢印 または `,` | 1フレーム戻って一時停止 |
| Home | 最初に戻って一時停止 |
| `-` または テンキー `-` | 遅くする |
| `=` または テンキー `+` | 速くする |
| F7 | 攻撃判定・くらい判定・接触判定の表示を切り替え |
| Backspace | 両者の入力履歴の表示を切り替え |
| F | 1P を操作介入で引き継ぐ |
| G | 2P を操作介入で引き継ぐ |
| Q | 操作介入を終了してリプレイに戻る |
| R | 操作介入の分岐をやり直す |
| 9 / 0 | 操作介入の入力遅延を減らす／増やす |

これらは「操作設定 -> モード操作設定」で変更できます。

リプレイは自動で再生されます。最初のフレームで一時停止したい場合は、「設定 -> リプレイと保存先... -> Pause at replay start」をオンにしてください。設定は `qoh99caster.ini` の `replayPauseAtStart=1` として保存されます。フレーム数と再生速度が表示され、一時停止中は再開キーを案内します。入力履歴と判定表示は初期状態では非表示です。

巻き戻しではメモリ内の近いチェックポイントを復元し、目的のフレームまでの短い区間だけを再計算します。保存間隔は最初は16フレームで、とても長いリプレイではキャッシュを256 MiB以内に収めるため間隔を広げます。チェックポイントは再生終了時に破棄されます。

### 操作介入

引き継ぎたいフレームで F か G を押します。カウントダウンの間リプレイは一時停止し、その後は自分の1P操作プロファイルが選んだキャラクターを動かし、もう一方は記録どおりに動き続けます。分岐は一時的なものです。Q でリプレイの状態に戻り、R で保存された分岐点からやり直せます。遅延の値は画面に表示され、`ddraw_wrapper.ini` に保存されます。

互換性のないゲーム／MODバージョンで作られたリプレイは再生できません。

## 共通の表示操作

| 既定のキー | 動作 |
|---|---|
| F11 | ウィンドウ表示と優先するフルスクリーンを切り替え |
| Insert | そのモードで使える場合、ゲーム内パネルを開閉 |
| Backspace | トレーニングとリプレイで入力表示を切り替え |

コントローラーの Start でもゲーム内パネルを開けます。これらはすべて「操作設定 -> モード操作設定」で変更できます。

ウィンドウはサイズ変更でき、ゲームの縦横比を保ちます。表示の設定は `ddraw_wrapper.ini` にあり、各項目に短い説明が付いています。通常はキャスターのメニューとゲーム内の操作で足ります。

## キャスターの設定

通常の設定は `qoh99caster.exe` から行います。

| メニュー | 内容 |
|---|---|
| 操作設定 | 操作の割り当てと、ラッパー・オンライン・トレーニング・リプレイのすべての操作 |
| 設定 -> 言語 | キャスターの表示を英語と日本語で切り替え |
| 設定 -> プレイヤーとファイル... | ニックネーム、ゲーム実行ファイル、注入するDLLのパス |
| 設定 -> 接続... | ホストポートと、内蔵ホールパンチサービスの情報 |
| 設定 -> サウンド... | BGMと効果音の音量 |
| 設定 -> ゲーム内表示とキー設定... | ゲーム本来のHUDの表示と、ゲーム内パネルの案内 |
| 設定 -> ゲーム設定(フルスクリーン、BGM、垂直同期)... | ゲーム本来の表示・BGM・タイミングの設定 |
| 設定 -> 追加機能(隠し F キー、FCommand.txt)... | ゲーム本来のオフライン開発者向け設定 |
| 設定 -> 自分の試合の観戦設定... | 観戦の可否、人数上限、観戦用ポート、手動で開放するもの |
| 設定 -> リプレイと保存先... | 記録、リプレイフォルダー、一覧の絞り込み、保存容量の警告 |

キャスターやゲームの隣に書き出されるファイル:

| ファイル | 内容 |
|---|---|
| `qoh99caster.ini` | キャスターの主な設定 |
| `qoh99caster-controls.json` | 操作とモード操作の割り当て |
| `ddraw_wrapper.ini` | ウィンドウ・描画・HUD・リプレイ表示 |
| `LocalConfig\FCommand.txt` | ゲーム本来のオフライン開発者設定 |
| `System\QOHcnf.key` | ゲーム本来の設定 |
| `palettes\` | 自作カラーのファイル |
| `replays\` | 記録された試合（変更しない場合） |
| `logs\session_*` または `logs\session_*.zip` | 失敗した実行の診断情報。保管時に ZIP 化されます |

`QOHcnf.key` と `FCommand.txt` を変更する前にゲームを閉じてください。どちらも保存時に直前の正常なファイルのバックアップが残ります。

## 困ったときは

### ウイルス対策ソフトの誤検知

ウイルス対策ソフトがウイルスだと言う、またはファイルが消える場合、それは誤検知です。多くの場合 Microsoft Defender です。

このMODはゲームを一時停止状態で起動し、`qoh99_netplay.dll` を読み込ませてから動かします。ソースコードが存在しない1999年のゲームにロールバック・ネットプレイ、トレーニング、リプレイを足すには、これ以外に方法がありません。本物のマルウェアも同じ手口を使うため、自動スキャナーはコードの中身を見ずに「形」で警告します。この部分はネットプレイを取り除かない限り無くせません。

スタートアップ登録もレジストリへの常駐もなく、隠蔽・パッキング・難読化もしていません。通信先はすべて[ネットワークの利用](#ネットワークの利用)に記載しています。

既にファイルが削除されてしまった場合:

1. 「Windows セキュリティ -> ウイルスと脅威の防止 -> 保護の履歴」を開きます。
2. 該当の検出を見つけて「復元」を選びます。先に復元してください。除外を追加しても、既に取り去られたファイルは戻りません。
3. `defender_exclusions.cmd` を管理者として実行するか、「ウイルスと脅威の防止 -> 設定の管理 -> 除外 -> 除外の追加 -> フォルダー」から手動でこのフォルダーを追加します。

`defender_exclusions.cmd` はただのテキストファイルなので、先に中身を読んでください。このフォルダー1つと、`qoh99caster.exe`、`qoh99_netplay.dll`、`ddraw.dll` のプロセス除外を追加します。ウイルス対策を無効化するものではありません。`defender_exclusions.cmd remove` で元に戻せます。除外したフォルダーはスキャンされないので、内容を信頼できるフォルダーだけを除外してください。

キャスターが起動時にファイルが無いと警告する場合も、同じ問題です。https://www.microsoft.com/en-us/wdsi/filesubmission からファイルを提出すると（「Software developer」->「Incorrectly detected as malware」を選択）、通常は数日で全利用者向けに検出が解除されます。

### キャスターを閉じてもゲームが残る

起きないはずです。ゲームはキャスターに結び付いており、キャスターが強制終了された場合も一緒に閉じます。ゲームが残るようなら、報告に値する不具合です。

### 対人戦・CPU戦・フリープレイで Fキーが効かない

ゲームを閉じ、「設定 -> 追加機能(隠し F キー、FCommand.txt)... -> 隠しFキー (F2..F9)」を TRUE にして「FCommand.txt に保存」を選びます。保存に失敗する場合は、ゲームが閉じていることと `LocalConfig` が書き込み可能であることを確認してください。トレーニングとリプレイは `FCommand.txt` を使いません。「操作設定 -> モード操作設定」で割り当ててください。

### エフェクトが正しく表示されない

ゲームを閉じ、「設定 -> ゲーム設定(フルスクリーン、BGM、垂直同期)... -> 16ビットカラー」を「はい」にして「QOHcnf.key に保存」を選びます。

### F11 でサイズが変わらない／小さな固定ウィンドウで起動する

「設定 -> ゲーム設定(フルスクリーン、BGM、垂直同期)...」で、フルスクリーンを「はい (通常 - ウィンドウサイズ変更可 + F11)」に設定して保存し、起動し直してください。ゲーム内部のフルスクリーン経路があって初めて、ラッパーはサイズ変更可能なウィンドウ・ボーダーレス・排他モードを提供できます。

### フルスクリーンから戻るとウィンドウが大きすぎる

ゲームを閉じ、`ddraw_wrapper.ini` の `ClientWidth` と `ClientHeight` を両方削除するか、`WindowScale` を小さくしてください。次回起動時に安全な既定サイズが作り直されます。

### 音楽が鳴らない

「設定 -> ゲーム設定(フルスクリーン、BGM、垂直同期)...」で BGM を Wave にし、BGMフォルダがゲームの `System\Bgm` を指しているか確認してください。CD音源は原盤が無いと無音です。「設定 -> サウンド...」で BGM音量が0でないかも確認してください。

### ゲームのビルドが違う／見つからないと言われる

対応している実行ファイル（[動作環境](#動作環境)を参照）を、それに対応する正しいゲームデータと一緒に使い、パスを「設定 -> プレイヤーとファイル...」で指定してください。無関係なビルドの名前を変えたり、一方の版の実行ファイルを他方のインストールへ上書きしたりしないでください。

`GAME.EXE` や `qoh99.exe` のファイル日付は目安にすぎません。11月版は 11/26、12月版は 12/12、PovertyHut Jr. は 2006年9月4日です。判定はハッシュで決まります。

### 相手のMODが古い／新しいと言われる

両者が同じリリース一式をインストールしてください。キャスター、`qoh99_netplay.dll`、`ddraw.dll`、`SDL3.dll` と付属ファイルをまとめて入れ替え、両者のキャスターを再起動します。

### オンライン対戦がつながらない

- 数値の `ip:port` と、「設定 -> 接続...」のホストポートを確認する。
- `qoh99caster.exe` の UDP をファイアウォールで許可する。
- 同じアドレスとポートで2つのホストを動かさない。
- 直接接続と自動ホールパンチの両方が失敗する場合は、全員のログを集める。
- 最後の手段として Radmin VPN や Hamachi などのVPNを使い、割り当てられたIPアドレスとキャスターが表示するポートで接続する。

### 観戦がタイムアウトする／映像が始まらない

- まず観戦ウィンドウのタイトルバーを見てください。WAITING FOR THE MATCH は接続に問題が無く、プレイヤー側のゲームが進んでいないことを意味します。BUFFERING の数値が増えない場合は、データが届いていません。REJECTED はホストが拒否したことを意味します。
- ホストが「ホストアドレスを知っている人全員」または「毎回確認する」を選んでいて、「誰にも許可しない」でないことを確認する。
- 観戦人数の上限に達していないか確認する。
- ホストの `ip:port` を数値のみで入力する（接頭辞や共有コードは不要です）。
- 同じ試行の観戦者・ホスト・参加者のセッションログを集める。経路ログに、どこで何が原因で失敗したかが記録されています。

### リプレイが再生できない

パッケージ一式と対応するゲームファイルを使ってください。拒否された理由はリプレイ一覧とログに表示されます。リプレイファイルを編集しないでください。

### オフラインでゲームが速すぎる／遅すぎる／カクつく

内容を理解している場合を除き、`FCommand.txt` のタイミング項目は既定値に戻してください。フレーム制限(QPC)は未設定、WaitCount はオフ、ExtraSkip はオフ、SetWaitTime は自動計測です。ゲームは通常、内部的におおよそ毎秒60.60フレームで動作します。

### コントローラーが出てこない／ボタン名がおかしい

同梱の `SDL3.dll` を `qoh99caster.exe` の隣に置いたまま、操作設定を開き直してください。コントローラーはプレイヤーごとに個別に選択します。Windows が曖昧に認識する場合は、重複した機器や使っていない機器を外してください。

### クラッシュ・挙動の異常・ネットプレイの遅延

通常の実行では診断ログを書き込みません。直近の情報を容量制限付きのメモリーに保持し、クラッシュ、同期ずれ、報告された実行時エラーの際に、それ以降の診断情報とともに保存します。完全な診断ログが必要な場合は、キャスターの起動前に `QOH99_LOG=1` を設定してください。`QOH99_WRAPPER_LOG=2` で描画の詳細ログも有効になります。強制終了や電源断では、テキストログが残らない場合があります。

異なるリリースのファイルを混ぜないでください。失敗した実行の `logs\session_*` フォルダーまたは `session_*.zip` を、`dll.log` とクラッシュダンプごと保管し、オンラインの場合は同じ試行の相手側のログも集めてください。

### ゲームが勝手に閉じる（例: オープニング直後）

必要なファイルが欠けているか壊れていると、ゲームは自分で終了します。その理由は `SYSTEM\QOHerror.txt` と、ログの `[game-error]` で始まる行（`dll.log` と `client.log` の末尾）にあります。たとえば `error:.\System\title\wall.img` という行は、そのファイルを名指ししています。確実に正常なコピー元から、ゲームフォルダー全体をもう一度コピーしてください。

## Wine と Proton

実際の Linux ハードウェアでの動作は検証していません。ベストエフォートとお考えください。

このパッケージには `launch_wine.sh` が含まれており、必要な Wine の上書き設定を付けてキャスターを起動します。ゲームフォルダーで次を実行してください。

```
bash launch_wine.sh
```

| フラグ | 効果 |
|---|---|
| `--check` | チェックだけを実行して終了します。助けを求めるときはこの出力を貼ってください。 |
| `--recheck` | 保存済みのマーカーを無視し、起動前に再チェックします |
| `--game-dir <path>` | `qoh99.exe` のあるフォルダー。既定はスクリプトのフォルダーです。 |
| `--strict` | チェックの失敗をすべて致命的として扱い、起動しません |

このスクリプトが認識するのは11月版の実行ファイルのプロファイルだけです。12月版の実行ファイルはチェック失敗と報告されますが、`--strict` を付けない限り起動します。何を受け付けるかの最終判断はキャスターが行います。

`ddraw.dll` の上書き設定を自分で行い、Wine から手動でキャスターを起動しても構いません。
